Custom Recognizers

Define your own detection rules — no code, no client restart needed. A pattern recognizer matches a regular expression (e.g. an internal employee ID format). A deny-list recognizer matches an exact set of terms (e.g. codenames, customer names). Changes reach connected clients on their next config poll (usually within 30s).
